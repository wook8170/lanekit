# 결정 기록

되돌리기 어렵거나 나중에 「왜 이렇게 했는가」를 묻게 될 결정을 여기에 남긴다. 결정 하나에 파일 하나를 둔다.

## 파일 이름

`<날짜>-<짧은 이름>.md` 로 쓴다. 예: `2026-01-05-allow-growth.md`. 틀은 `0000-template.md` 다.

## 언제 쓰는가

- 구조 · 의존성 · 데이터 형식처럼 여러 파일에 걸치는 선택을 했을 때
- 게이트의 기준선을 늘려서 다시 잠글 때. 재잠금 명령의 `--decision` 에 이 폴더의 파일 이름(확장자 제외)을 넘긴다
- 사용자가 맡긴 결정을 권장안으로 진행했을 때. 「결정한 사람」 칸에 위임이라고 적는다

## 지킬 것

- 한 번 쓴 결정은 고치지 않는다. 바뀌면 새 파일을 쓰고, 앞 파일의 상태를 「대체됨」으로 바꾼 뒤 새 파일을 가리킨다.
- 선택지를 하나만 적지 않는다. 버린 선택지와 버린 이유가 있어야 나중에 다시 판단할 수 있다.
- 「뒤집는 조건」을 적는다. 어떤 사실이 바뀌면 이 결정을 다시 볼지 적어 둔다.
