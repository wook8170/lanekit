# 메모리 안내

Claude Code 의 메모리는 저장소 밖 개인 폴더에 있다. 세션마다 색인(`MEMORY.md`)이 통째로 읽히므로, 색인이 커지면 모든 세션의 맥락이 줄어든다. 이 문서는 메모리에 넣을 것과 넣지 않을 것을 가른다.

## 메모리에 넣는 것

- 함정: 이 저장소와 이 머신에서 겪은, 다시 겪기 쉬운 문제와 피하는 법
- 사고: 한 번 일어난 사고의 원인과 재발을 막는 방법
- 개인 선호: 보고의 형식처럼 사람마다 다른 것

## 메모리에 넣지 않는 것

| 내용 | 둘 곳 |
|---|---|
| 모두가 지킬 규칙 | `AGENTS.md` |
| 결정과 그 이유 | `docs/decisions/` |
| 출하 기록 · 버전 계획 | 릴리스 노트와 문서 |
| 지금 하는 일의 상태 | `progress.md` |
| 코드를 읽으면 알 수 있는 것 | 넣지 않는다 |

규칙을 메모리에만 두면 다른 사람과 CI 가 그 규칙을 알 수 없다. 그래서 규칙은 저장소의 파일에 둔다.

## 크기 기준

- 색인이 150줄 또는 20 KB 를 넘으면 `lanekit doctor` 가 경고한다.
- 색인의 한 줄은 「이름 — 언제 필요한가」 한 문장으로 쓴다. 자세한 내용은 항목 파일에 둔다.
- 끝난 일의 기록은 지운다. 규칙으로 굳은 항목은 `AGENTS.md` 로 옮기고 메모리에서 지운다.

## 시작 세트

`lanekit init` 은 여러 프로젝트에서 되풀이된 원칙과 함정을 모은 시작 세트를 `.lanekit/init-suggestions/memory/MEMORY.md` 에 둔다. 메모리 폴더에는 쓰지 않는다. 필요한 항목만 골라 직접 옮긴다.
