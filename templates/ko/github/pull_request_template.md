## 리뷰 방식

하나를 고른다.

- [ ] 작성자가 아닌 사람이 승인한다
- [ ] 작성한 세션과 다른 맥락의 에이전트가 검수했다(검수 보고의 위치를 적는다)
- [ ] 리뷰 없이 합친다(이유를 적는다)

## 검증

- [ ] `node scripts/lanekit/gate.mjs --profile changed` 통과
- [ ] 기능 변경에 맞춰 테스트를 고쳤다
- [ ] 기능 변경에 맞춰 문서를 고쳤다(해당 없으면 확인한 근거를 적는다)
